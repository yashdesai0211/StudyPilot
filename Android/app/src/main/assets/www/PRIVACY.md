# StudyPilot — Privacy Notice (Draft)

**Last updated: 5 November 2026**  
**Product creator: Yash Desai**

StudyPilot is designed to work without an account. In this release, subjects, chapters, notes, quiz records, preferences and focus-session records are stored locally in the browser or installed web app on the device where they are entered.

## Information handling

- StudyPilot does not ask for an email address, phone number, password or account registration.
- Study records are stored in local browser storage (IndexedDB).
- This release does not intentionally send study records to a StudyPilot server; it has no cloud database, external AI/API connection, advertising SDK or analytics tracker.
- If a user exports a backup, the resulting file is saved using the browser's download mechanism. The user is responsible for protecting that file.
- Hosting providers and browsers may process ordinary technical request data under their own privacy terms when the website is accessed online.

## User choices

Users can export a backup, import a previously exported backup, or delete locally stored StudyPilot data from Settings. Deleting browser storage or uninstalling/resetting the browser may also remove records. Data cannot be restored without a backup.

## Security limits

Local browser storage is not encrypted by this application. Anyone with access to an unlocked device and browser profile may be able to access stored records. Do not store passwords, sensitive personal details, or another person's private information. Use the device's screen lock and keep backups secure.

## Children and teenagers

StudyPilot may be used by students, including minors. This release intentionally avoids account creation and collection of student profiles on a server. Before adding any online account, cloud sync, analytics, advertising, public sharing or other collection of personal data, the product must undergo a fresh legal and privacy review with appropriate safeguards and any required parental/guardian consent processes.
