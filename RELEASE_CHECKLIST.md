# StudyPilot release checklist

- [ ] Run the website locally and verify every screen and CRUD action.
- [ ] Verify IndexedDB persistence after closing/reopening the browser.
- [ ] Test JSON export and import using a disposable test profile.
- [ ] Test offline reload after the service worker has cached the app.
- [ ] Test responsive layout on a real Android device.
- [ ] Build and install the Android debug APK; test back navigation and local data persistence.
- [ ] Build and launch the Windows EXE on a clean Windows account/device with WebView2 Runtime.
- [ ] Verify all platform builds show “Created by Yash Desai”.
- [ ] Review privacy/terms with a qualified professional before commercial public launch.
- [ ] For Play Store: configure release signing securely, prepare store assets, complete policy declarations and test the signed release.

Do not describe a platform as fully tested until its checklist items have been completed on that platform.
